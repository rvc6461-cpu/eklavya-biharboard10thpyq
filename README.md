# Eklavya Prep Hub

Read this complete specification carefully before generating the application. Do not skip any section. Follow all requirements, features, UI/UX guidelines, offline and online behavior, premium system, and future scalability instructions.



## App Overview



Create a modern, premium, lightweight Android application named "Eklavya – Bihar Board 10th PYQ, Mock Test & Notes" exclusively for Class 10 Bihar Board students.



The app should provide a complete preparation ecosystem focused on:

- Chapter-wise Previous Year Questions (PYQ)

- Full-length Mock Tests

- Previous Year Question Papers PDF

- Formula Sheets & Quick Revision

- Performance Analytics

- Smart Study Planning

- Premium Handwritten Notes



The application should not feel like a simple quiz app. It should look like a professional EdTech platform with premium design, excellent user experience, and smooth performance.



App Motto:

"No Distraction. Just Practice. Improve Every Day."
